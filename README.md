## How I build AI products

- **Evals before features.** Golden datasets and weekly Label Studio annotation reviews across four AI products: Ivy, Livy, Resume Fitment and Interview Insights.
- **Behaviour is a product decision.** I write the system prompts and safety guardrails, and set the fine-tuning strategy.
- **Prototype to decide, not to demo.** A Storybook workbench on Claude Code and DevPod lets me ship UI and commit to GitHub with engineering, closing the design to engineering handoff gap.
- **Agents for my own operating system.** A chief-of-staff agent and a competitor-intelligence agent built on Claude and MCP (Notion, Slack, HubSpot, Linear) save 8 to 12 hours a week. MCP also drives our weekly release notes.
- **Data moats, deliberately.** Partnered with data science on a skill graph reused across screening, interviewing and evaluation, built on a 14-year interview corpus.
